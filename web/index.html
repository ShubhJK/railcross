Under the hood

Built on solid Object-Oriented C++

Every crossing is an object. Every route is a composition. The status engine runs on polymorphism.

🧩

Abstraction

Abstract base Crossing defines what a crossing must do.

🔒

Encapsulation

Gate status is private. Outside code reads via getters only.

🧬

Inheritance

LevelCrossing extends Crossing and reuses its logic.

🎭

Polymorphism

expectedWaitSeconds() is virtual — each type computes its own wait.

🔗

Composition

A Route has-a collection of crossings.

➕

Operator Overloading

operator< lets std::sort rank routes by real travel time.
